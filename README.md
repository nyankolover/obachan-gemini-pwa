# おばあちゃん専用 Gemini PWA (見守り & 詐欺防止ガードレール付き)

おばあちゃんがiPhoneで安心して使える、シニア向けAIアシスタントWebアプリ（PWA）です。  
公式のGeminiアプリそっくりの親しみやすい画面で、**音声（マイク）や画面写真でなんでも質問**できます。

裏側では孫（管理者）が**全相談内容をリアルタイムで把握**し、**詐欺や危険な話題が出た際はAIが絶対に自己判断させず「洸晟に電話して」と誘導するガードレール**を備えています。

---

## 🌟 主な特徴

1. **おばあちゃんに優しいUI/UX**
   * **大きな文字・高いコントラスト**: 視力が落ちていても読みやすい文字サイズ。
   * **特大マイクボタン**: タップして声で話すだけで、文字入力なしで質問可能（Web Speech API）。
   * **写真添付（カメラ・スクショ）**: 「この画面あやしい？」「この手紙なに？」とスマホのカメラや画面スクショを直接送れる。
   * **PWA（ホーム画面追加）対応**: iPhoneのホーム画面にアプリアイコンを置くと、全画面でネイティブアプリのように起動。

2. **📰 詐欺広告撲滅作戦**
   * **ワンタップ相談ボタン**: 「📰 この広告あやしい？」「📱 この画面なに？」「✉️ このメール本物？」「📞 知らない電話が来た」を押すだけ。写真（スクショ）を選ぶと自動で送信。
   * **詐欺広告専用の判定モード**: 偽ウイルス警告、偽当選、有名人を使った投資広告、偽通販、宅配・銀行を装うSMSなどを画像から読み取り、回答の1行目で「⚠️ 詐欺の可能性が高い／🟡 押さずに洸晟に見せて／🟢 普通の広告」を明言。
   * **キーワード安全網**: Geminiが落ちていても「ギフトカード」「遠隔操作」「ウイルスに感染」「還付金」などの強いパターンは必ず警告＆通報（[`localRiskCheck_`](backend/Code.gs)）。
   * **iPhone丸ごと防御の手順書**: NextDNS・Safari・SMS/電話フィルタ・スクリーンタイムで遠隔操作アプリを入れさせない設定まで → [docs/SCAM_AD_BLOCKING.md](docs/SCAM_AD_BLOCKING.md)

3. **📞 Gemini ＋ 俺の超安全相談窓口**
   * **プロンプト・ガードレール**: 危険な話題のときは、AIが「⚠️ これは詐欺の可能性が高いです！お金を払わず、今すぐ洸晟に電話してね」と安全誘導。
   * **📞 洸晟に電話ボタン**: 右上に常設。危険判定のときは吹き出しの中に特大の「📞 洸晟に電話する」が出る（番号はGASの `KOSEI_TEL` から自動配信）。
   * **🆘 洸晟にすぐ知らせるボタン**: Geminiを通さず、Discord＋メールに即時通報。おばあちゃんは「何もせず待つ」だけ。
   * **孫からの伝言**: GASの `KOSEI_MESSAGE` に書いた一言が、回答の下に「💡 孫（洸晟）からのメッセージ」として表示される。
   * **🔊 読んで**: 回答を音声で読み上げ。

4. **🚨 俺への自動通報付き**
   * **Discord #Claudenotice へ即時通知**: 全相談をリアルタイム通知。危険度60以上と🆘は `DISCORD_MENTION` でメンション付き（スマホが鳴る）。
   * **メール二重通報**: 危険時・🆘時は `NOTIFY_EMAIL` にもメール。Discordが落ちていてもメールにフォールバック。
   * **Googleスプレッドシートへの全件保存**: 相談内容・危険度・判定理由・モードを全件記録。
   * **📊 月次レポート**: 毎月1日に先月の相談回数・危険フラグ件数・カテゴリ別集計をDiscordとメールに自動送信（`setupMonthlyReportTrigger()` を一度実行）。

## 🏗️ 構成図

```text
【おばあちゃんのiPhone】
  ホーム画面の「Gemini」アイコン（PWA）
  ・声（マイク）や写真で相談
       │
       ▼ HTTPS POST (JSON)
【Google Apps Script (バックエンド)】
  ├── ① 全相談をスプレッドシート「おばあちゃんGemini見守りログ」に自動保存
  ├── ② Gemini API（gemini-3.6-flash 等）で画像・質問を解析 ＆ 危険度判定
  │     └── 「📰 広告チェック」モードは詐欺広告専用プロンプト
  │     └── Gemini失敗時もキーワード安全網で警告
  ├── ③ Discord #Claudenotice に即時通知（危険度60以上はメンション付き警告）
  ├── ④ 危険時・🆘時はメールにも二重通報（Discord失敗時のフォールバック兼用）
  └── ⑤ 毎月1日に月次レポートを自動送信（時間主導トリガー）
       │
       ▼ 回答 (JSON) ＋ 洸晟の電話番号 ＋ 孫からの伝言
【おばあちゃんのiPhone画面】
  親切で安全な回答。危険なら赤い吹き出し＋「📞 洸晟に電話する」「🆘 洸晟にすぐ知らせる」
```

## 🚀 セットアップ手順

### ステップ 1: バックエンド (Google Apps Script) の準備

1. [Google Apps Script](https://script.google.com/) を開く。
2. 「新しいプロジェクト」を作成し、プロジェクト名を `おばあちゃんGemini見守りPWA` とする。
3. `backend/Code.gs` の中身をエディタに貼り付けて保存（Ctrl+S）。
4. 左メニューの **「プロジェクトの設定（歯車マーク）」** ➡ **「スクリプト プロパティ」** に以下を追加：
   * `SHARED_SECRET`: 任意の英数字20文字以上（PWAアプリ側と合わせる合言葉）【必須】
   * `GEMINI_API_KEY`: Google AI Studio で取得したAPIキー【必須】
   * `DISCORD_WEBHOOK_URL` (または `DISCORD_BOT_TOKEN`): Discord通知用
   * `DISCORD_MENTION`: 危険時・🆘時にメンションする相手（例: `<@あなたのDiscordユーザーID>` または `@everyone`）
   * `NOTIFY_EMAIL`: 危険時・🆘時・Discord失敗時にメールで通報する宛先（自分のGmailなど）
   * `KOSEI_TEL`: 洸晟の電話番号（例: `09012345678`）→ アプリに📞ボタンが出る
   * `KOSEI_MESSAGE`: おばあちゃんへの伝言（任意。例: `今週の土曜に遊びに行くね`）
5. 右上の **「デプロイ」** ➡ **「新しいデプロイ」** をクリック：
   * 種類の選択: **「ウェブアプリ」**
   * 次のユーザーとして実行: **「自分」**
   * アクセスできるユーザー: **「全員」**
6. 発行された **「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）を控えておく。
   ブラウザでそのURLを開いて `{"ok":true,...}` が出れば動作確認OK。
7. GASエディタで関数を選んで実行（初回は権限の承認が出る）:
   * `testNotify()` … Discordとメールにテスト通報が届くか確認
   * `setupMonthlyReportTrigger()` … 毎月1日 9時の月次レポートを登録（`sendMonthlyReport()` を直接実行すると今すぐ試せる）

---

### ステップ 2: フロントエンド (GitHub Pages) の公開

1. 本リポジトリの **Settings** ➡ **Pages** を開く。
2. **Build and deployment** の Source で **「Deploy from a branch」** を選択し、Branch を `main` / `/(root)` にして「Save」。
3. 1〜2分で公開URLが発行される（例: `https://nyankolover.github.io/obachan-gemini-pwa/`）。

---

### ステップ 3: おばあちゃんのiPhoneへの設定（所要時間 3分）

1. おばあちゃんのiPhoneの **Safari** で以下の設定用URLを開く：
   ```text
   https://nyankolover.github.io/obachan-gemini-pwa/?endpoint=【GASのウェブアプリURL】&secret=【SHARED_SECRET】&tel=【洸晟の電話番号】
   ```
   * ※URLパラメータによって、おばあちゃんの手動入力なしで自動設定されます。
   * ※`tel` は省略可。GASの `KOSEI_TEL` を設定していれば、最初の相談のあとに自動で📞ボタンが出ます。
2. 画面下部の中央にある **「共有ボタン（四角から矢印が出ているアイコン）」** をタップ。
3. メニューから **「ホーム画面に追加」** を選択 ➡ 右上の「追加」を押す。
4. ホーム画面に **「Gemini」** のアプリアイコンが並べば設定完了です！
5. アイコンをタップして起動し、マイクボタンを押して「今日の天気は？」などとテストしてみてください。
6. 一緒に「📰 この広告あやしい？」→ 写真を選ぶ → 判定が出る、までを一度練習しておくと安心です。

## 👵 おばあちゃんに教えること（3つだけ）

1. あやしい広告・画面・メールが出たら **「📰 この広告あやしい？」を押して写真を選ぶ**
2. 赤い画面になったら **「📞 洸晟に電話する」** を押す
3. 誰かに「お金」「カード」「番号」と言われたら、**何もせず 🆘 を押す**

## 📵 詐欺広告撲滅作戦（iPhone丸ごと防御）

このアプリは「最後の砦」です。その手前で詐欺広告・偽警告・偽SMSが**そもそも届かない**ようにする手順を
[docs/SCAM_AD_BLOCKING.md](docs/SCAM_AD_BLOCKING.md) にまとめています（所要30〜40分・すべて無料）。

| 防壁 | 内容 |
|---|---|
| ① NextDNS | 端末全体の広告・詐欺ドメインを遮断（Security全ON、新規登録ドメイン遮断、OISD / HaGeZi / 280blocker） |
| ② Safari | 詐欺Webサイトの警告・ポップアップブロック・コンテンツブロッカー（AdGuard / 280blocker） |
| ③ 連絡経路 | 不明な発信者を消音、不明な差出人をフィルタ、LINEのメッセージ受信拒否、キャリアの迷惑電話ブロック |
| ④ スクリーンタイム | **アプリのインストールを「許可しない」** → 遠隔操作アプリ（AnyDesk等）を入れさせない |
| ⑤ 最後の砦 | 本アプリの 📰 広告チェック ＋ 📞/🆘 で洸晟に直結 |

## 🧪 開発メモ

* フロントは素のHTML/CSS/JS（ビルド不要）。`sw.js` の `CACHE_NAME` を上げると全端末のキャッシュが更新されます。
* `backend/Code.gs` のキーワード安全網（`localRiskCheck_` / `applyHeuristic_`）はGAS非依存なので、Node.jsで切り出して単体テストできます。
* 危険度のしきい値はフロント `RISK_ALERT_AT`（app.js）とバックエンド `NOTIFY_AT`（Code.gs）で揃えています（既定60）。
