# おばあちゃん専用 Gemini PWA (見守り & 詐欺防止ガードレール付き)

おばあちゃんがiPhoneで安心して使える、シニア向けAIアシスタントWebアプリ（PWA）です。  
公式のGeminiアプリそっくりの親しみやすい画面で、**音声（マイク）や画面写真でなんでも質問**できます。

裏側では孫（管理者）が**全相談内容をリアルタイムで把握**し、**詐欺や危険な話題が出た際はAIが絶対に自己判断させず「洸晟に電話して」と誘導するガードレール**を備えています。

---

## 🌟 主な特徴

1. **おばあちゃんに優しいUI/UX**
   * **大きな文字・高いコントラスト**: 視力が落ちていても読みやすい文字サイズ。
   * **特大マイクボタン**: タップして声で話すだけで、文字入力なしで質問可能（Web Speech API）。
   * **写真添付（カメラ・スクショ）**: 「この画面あやしい？」「この手紙なに？」とスマホのカメラや画面スクショを直接送れる。
   * **PWA（ホーム画面追加）対応**: iPhoneのホーム画面にアプリアイコンを置くと、全画面でネイティブアプリのように起動。

2. **鉄壁のセキュリティ ＆ 見守り機能（バックエンド）**
   * **詐欺・危険話題の自動検知**: 還付金、ギフトカード購入、ウイルス警告画面、遠隔操作ソフト、暗証番号などの話題をGemini APIが自動採点（危険度0〜100）。
   * **プロンプト・ガードレール**: 危険な話題のときは、AIが「⚠️ これは詐欺の可能性が高いです！お金を払わず、今すぐ洸晟に電話してね」と安全誘導。
   * **Discord #Claudenotice へ即時アラート**: おばあちゃんが相談した瞬間、相談内容と判定理由がリアルタイム通知。
   * **Googleスプレッドシートへの全件保存**: 過去のやり取りが全てスプレッドシートに記録され、いつでも見返せる。

## 🏗️ 構成図

```text
【おばあちゃんのiPhone】
  ホーム画面の「Gemini」アイコン（PWA）
  ・声（マイク）や写真で相談
       │
       ▼ HTTPS POST (JSON)
【Google Apps Script (バックエンド)】
  ├── ① 全相談をスプレッドシート「おばあちゃんGemini見守りログ」に自動保存
  ├── ② Gemini API（gemini-3.6-flash 等）で画像・質問を解析 ＆ 危険度判定
  └── ③ Discord #Claudenotice に即時通知（危険度60以上は警告アラート）
       │
       ▼ 回答 (JSON)
【おばあちゃんのiPhone画面】
  親切で安全な回答が表示される
```

## 🚀 セットアップ手順

### ステップ 1: バックエンド (Google Apps Script) の準備

1. [Google Apps Script](https://script.google.com/) を開く。
2. 「新しいプロジェクト」を作成し、プロジェクト名を `おばあちゃんGemini見守りPWA` とする。
3. `backend/Code.gs` の中身をエディタに貼り付けて保存（Ctrl+S）。
4. 左メニューの **「プロジェクトの設定（歯車マーク）」** ➡ **「スクリプト プロパティ」** に以下を追加：
   * `SHARED_SECRET`: 任意の英数字20文字以上（PWAアプリ側と合わせる合言葉）
   * `GEMINI_API_KEY`: Google AI Studio で取得したAPIキー
   * `DISCORD_WEBHOOK_URL` (または `DISCORD_BOT_TOKEN`): Discord通知用
5. 右上の **「デプロイ」** ➡ **「新しいデプロイ」** をクリック：
   * 種類の選択: **「ウェブアプリ」**
   * 次のユーザーとして実行: **「自分」**
   * アクセスできるユーザー: **「全員」**
6. 発行された **「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）を控えておく。

---

### ステップ 2: フロントエンド (GitHub Pages) の公開

1. 本リポジトリの **Settings** ➡ **Pages** を開く。
2. **Build and deployment** の Source で **「Deploy from a branch」** を選択し、Branch を `main` / `/(root)` にして「Save」。
3. 1〜2分で公開URLが発行される（例: `https://nyankolover.github.io/obachan-gemini-pwa/`）。

---

### ステップ 3: おばあちゃんのiPhoneへの設定（所要時間 3分）

1. おばあちゃんのiPhoneの **Safari** で以下の設定用URLを開く：
   ```text
   https://nyankolover.github.io/obachan-gemini-pwa/?endpoint=【GASのウェブアプリURL】&secret=【SHARED_SECRET】
   ```
   * ※URLパラメータによって、おばあちゃんの手動入力なしで自動設定されます。
2. 画面下部の中央にある **「共有ボタン（四角から矢印が出ているアイコン）」** をタップ。
3. メニューから **「ホーム画面に追加」** を選択 ➡ 右上の「追加」を押す。
4. ホーム画面に **「Gemini」** のアプリアイコンが並べば設定完了です！
5. アイコンをタップして起動し、マイクボタンを押して「今日の天気は？」などとテストしてみてください。

---

## 📱 スマホ全体の広告・詐欺ブロック (NextDNS) との併用

iPhone端末全体の通信（Safari以外のブラウザやアプリ内広告）もブロックするため、**NextDNSの暗号化DNSプロファイル**を併せてインストールしておくことを推奨します。

1. [NextDNS](https://nextdns.io/) でアカウントを作成。
2. おばあちゃんのiPhoneのSafariで `https://apple.nextdns.io/` を開く。
3. NextDNSのIDを入力して構成プロファイルをダウンロード。
4. iPhoneの「設定」➡「プロファイルがダウンロード済み」➡「インストール」。
